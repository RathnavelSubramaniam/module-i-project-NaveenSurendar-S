#  AI-Driven Sentiment Analysis for Stock Market Insights

## Overview

This project leverages **Natural Language Processing (NLP)** and **Machine Learning** to analyze financial news sentiment and understand its impact on stock market trends. By classifying news articles as positive, negative, or neutral, the model provides valuable insights that can assist investors and analysts in making informed decisions.

---

## Features

- Sentiment analysis of stock market news
- News text preprocessing using NLP techniques
- Machine Learning model for sentiment classification
- Analysis of stock prices with sentiment data
- Data visualization for better insights
- Performance evaluation using classification metrics

---

## Dataset

The dataset contains the following attributes:

| Column | Description |
|--------|-------------|
| Date | Date of the news article |
| News | Financial news headline/article |
| Open | Opening stock price |
| High | Highest stock price |
| Low | Lowest stock price |
| Close | Closing stock price |
| Volume | Trading volume |

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/AI-Driven-Sentiment-Analysis.git
```

Navigate to the project folder:

```bash
cd AI-Driven-Sentiment-Analysis
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open:

```
Project_I_GenAI.ipynb
```
